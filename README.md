# Number Guessing Game 

A simple command-line game built in Python where the player tries to guess a randomly generated number between 1 and 100. The game gives hints ("higher" or "lower") after each guess and tracks how many attempts it took to win.

# 📖 Project Description

This project was built as a practice exercise to strengthen fundamentals in Python, specifically working with the random module, loops, conditionals, user input, and formatted strings (f-strings). The game randomly selects a secret number and prompts the player to guess it, offering feedback after every guess until the correct number is found.

# 🚀 Features

Randomly generates a number between 1 and 100
Takes user input and validates guesses against the target number
Provides real-time hints ("Lower Number Please!" / "higher Number Please!")
Tracks and displays the total number of attempts taken to guess correctly

# 🎮 Example Gameplay

Guess a Number: 50

Lower Number Please!

Guess a Number: 25

higher Number Please!

Guess a Number: 37

You have guessed the number, 37 correctly in 3 attempts, Congrats!
